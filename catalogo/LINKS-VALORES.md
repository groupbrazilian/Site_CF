## Atualizar o cadastro

Acrescente ou substitua uma linha dentro de `links`, por exemplo:

```js
  "TK1010": "https://www.brazilianimports.com.br/sacador-sextavado-da-porca-superior-da-polia-do-cvt-46mm"
```

Mantenha a vírgula entre as linhas. Use o código exatamente como está no catálogo e o link completo HTTPS do produto da Brazilian Imports. Depois, atualize a versão de `loja.js` no `index.html` para evitar cache antigo ao publicar. Nenhuma alteração no Apps Script é necessária.
