# Plano de Migração SEO — CF Industrial

## Objetivo
Migrar a presença principal para `https://www.cfindustrial.com.br` sem perder sinais acumulados no domínio anterior.

## Etapas
1. Inventariar todas as URLs indexadas do domínio antigo.
2. Definir a URL nova equivalente para cada página relevante.
3. Configurar redirecionamento **301 página a página** no domínio antigo.
4. Evitar redirecionar todas as URLs indiscriminadamente para a Home.
5. Atualizar links internos, canonical, sitemap e dados estruturados.
6. Adicionar e verificar o novo domínio no Google Search Console.
7. Enviar o novo sitemap.
8. Usar a ferramenta de mudança de endereço do Search Console se aplicável ao cenário.
9. Atualizar Perfil da Empresa no Google, Bing Places, redes sociais e diretórios.
10. Monitorar 404, cobertura, impressões, cliques e posições.
