# Checklist de Publicação — CF Industrial

## Conteúdo e comercial
- [ ] Logo oficial aplicada
- [ ] Fotos reais aplicadas
- [ ] E-mail confirmado
- [ ] Telefones confirmados
- [ ] Capacidades técnicas das máquinas confirmadas
- [ ] Projetos reais inseridos
- [ ] Mensagens de WhatsApp testadas
- [ ] Textos revisados com a equipe CF Industrial

## SEO técnico
- [ ] Titles e descriptions revisados
- [ ] Canonicals apontando para domínio final
- [ ] Sitemap acessível
- [ ] robots.txt acessível
- [ ] Schemas validados
- [ ] Favicon carregando
- [ ] 404 testada
- [ ] Search Console configurado
- [ ] Bing Webmaster Tools configurado
- [ ] Redirecionamentos 301 do domínio antigo planejados

## Performance
- [ ] Imagens WebP comprimidas
- [ ] Hero abaixo de ~300 KB quando possível
- [ ] Demais imagens lazy loading
- [ ] Lighthouse mobile verificado
- [ ] CLS/LCP/INP revisados

## Responsividade e UX
- [ ] Menu mobile
- [ ] CTAs no mobile
- [ ] Formulário para WhatsApp
- [ ] Telefone clicável
- [ ] Navegação por teclado
- [ ] Contraste
- [ ] Teste em Chrome, Edge, Safari e Android/iOS quando possível
